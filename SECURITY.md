# Security

This public repository must contain no credentials, private user data, production endpoint secrets, service-role keys, or private cloud configuration. Report concerns privately through [ADD_PRIVATE_SECURITY_CONTACT]. Do not open a public issue containing sensitive details.

If a secret is exposed, rotate it immediately, remove it from the working tree and Git history, and review related access logs. Inspect all staged files and full Git history before publishing. This document intentionally omits operational security mechanisms.
