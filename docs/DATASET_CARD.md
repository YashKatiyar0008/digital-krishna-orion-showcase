# Dataset Card

## Purpose and scope

The dataset is designed to train culturally grounded, multilingual, structured general-life guidance. Target languages are English, Hindi, and Hinglish. Task categories may include greetings, clarification, study, discipline, career, comparison, anger, family, spiritual questions, and safety boundaries.

It is intended to include response-length variation, multi-turn exchanges, clarification cases, and boundary-setting examples. Coverage must be verified before publication.
