# Orion Rubric Mapping

## Innovation & Creativity — 25%

The implemented innovation is domain-specific SFT for culturally grounded behavior; multilingual response design; a clear separation between learned behavior and verified retrieval; a practical action framework; and a non-generic approach to cultural AI. Adapter and dataset artifacts are verified locally; blind quality results remain pending.

## Technical Excellence — 25%

Evidence may cover a custom dataset, verified LoRA/QLoRA method, held-out evaluation pipeline, model serving, safety boundaries, versioning, multilingual tests, and a scalable deployment concept. Each item must be labeled implemented, in progress, planned, or private after review.

## Real-World Impact — 20%

Possible metrics include response usefulness, language accessibility, action-plan completion, return usage, latency, test-user satisfaction, and safety pass rate.

- Tested metrics: 30/30 deterministic safety/retrieval scenarios passed; no public user-impact metrics are yet available.
- Planned metrics: blind preference, usefulness, multilingual quality, actionability, latency, satisfaction, and safety pass rate on held-out prompts.

## User Experience & Design — 15%

The product has a private web interface with multilingual chat, journaling, breathing, scriptures, stories, and voice-oriented assets. Public screenshots, formal accessibility testing, and evidence links remain pending.

## Presentation & Demonstration — 15%

The presentation should combine a fair base-versus-SFT comparison, real training evidence, a memorable story, transparent limitations, a working live experience, and a tested backup demo.
