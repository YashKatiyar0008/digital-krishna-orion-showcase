# Results

This folder contains verified summaries and a reproducible evaluation runner. The 2 August 2026 base-versus-SFT run uses 12 deterministically selected private held-out English prompts, four supplemental Hindi/Hinglish prompts, and one supplemental safety prompt. It publishes aggregate scores, hashes, and per-case score metadata while keeping private held-out prompts and raw outputs restricted.

The automated rubric is reproducible but is not a substitute for human blind review. The current results expose weaknesses in SFT actionability and safety; they should guide remediation rather than be presented as proof of superiority.
