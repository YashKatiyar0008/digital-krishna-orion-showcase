# Public Disclosure Policy

## Public

- Project overview and architecture overview
- Real, redacted screenshots and demo link
- Sanitized data samples
- Public model and dataset cards
- Verified evaluation summary
- Safety documentation

## Restricted to judges

- Selected training logs and adapter proof
- Private technical walkthrough
- Selected, reviewed implementation evidence

## Private

- Production source code and complete dataset
- Adapter weights and system prompts
- Private retrieval corpus and database structure
- Deployment details, credentials, and private user data
